Smart College Bus Tracking and Management System

Overview
This repository contains the Software Engineering Case Study Analysis for the Smart College Bus Tracking and Management System. The project explores a modernized, cloud-based solution to track college transit vehicles in real-time, improving the commuting experience for students and faculty while providing actionable analytics to the college administration.

Key Features
- Real-Time GPS Tracking: Live location updates for students and transport administrators.
- Accurate ETAs: Traffic-aware Estimated Time of Arrival calculations.
- Proximity Alerts: Push notifications to users when their bus is approaching.
- Administrative Dashboard: Centralized fleet management, route configuration, and analytics.

Software Engineering Highlights
- Methodology: Agile Scrum Framework.
- Architecture: Cloud-based Client-Server architecture utilizing microservices.
- System Models: Complete UML representations including Use Case, Activity, Class, Sequence, ER diagrams, and Data Flow Diagrams (Level 0 and 1).
